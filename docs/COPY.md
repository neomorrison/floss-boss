# Floss Boss: Copy rules

The interface speaks in product voice; the characters (patients, Dr. Ruth Canal, reviews) are where the jokes live.

## Hard rules (every string)
- No em dashes. Use periods, commas, colons or parentheses. En dashes only in numeric ranges.
- No emoji in the interface. Use the SVG icon set.
- Numbers go through `src/core/format.ts` (`money`, `pct`, `clock`, `duration`).

## Interface copy (buttons, labels, headings, errors, tooltips)
- Plain verbs, shortest label that makes sense: Clean, Quick clean, Hire, Fire, Train, Buy, Upgrade, Open practice, Move, Claim, Done.
- Say what the player does, not how the software works. Do not explain obvious controls.
- No narrator voice, no "let's", no "you're all set", no "simply", no "just".
- No exclamation marks in interface copy.
- State problems plainly: "Not enough cash", "Needs level 4", "Every operatory is staffed".
- One vocabulary: operatory (not room or chair) for the cubicle, chair for the chair tier, patient (not client), hygienist, tartar, plaque, stain, cash, rating.
- Sentence case for buttons and labels, Title Case for screen names and item names.

## Character copy (speech bubbles, reviews, flavour blurbs, result lines)
- Short and silly is good. Exclamation marks are fine inside speech bubbles ("Ow!").
- Gross-but-fun, never mean about bodies, never medical advice.
- Dr. Ruth Canal is warm, a little dramatic, loves a pun.
