# Floss Boss

A dental hygienist sim. Scrape tartar and polish smiles by hand in a 3D mouth, save up, open your own practice, hire hygienists who clean patients for you, and grow a chain of clinics.

Play: https://neomorrison.github.io/floss-boss/

## Develop

```bash
npm install
npm run dev
```
